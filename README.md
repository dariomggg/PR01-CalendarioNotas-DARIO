# Calendario de notas

## Descripción
Aplicación web que permite gestionar notas organizadas por meses.  
Las notas se guardan en el navegador mediante localStorage.

## Instrucciones de uso
Abrir index.html, seleccionar un mes y crear una nota con título y descripción.  
Las notas pueden editarse o eliminarse desde la página del mes.  
En la página principal se pueden guardar todas las notas o limpiar el calendario.
